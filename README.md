# telegram_bot_cryptopanic_news

Новостной бот: получает публикации CryptoPanic, извлекает текст, переводит через DeepL и отправляет в Telegram.

- Получение новостей и извлечение текста статьи.

## Подготовка и запуск

Это сохранённая версия пет-проекта, показывающая этап развития навыков. Для воспроизведения создайте отдельное окружение Python, совместимое с зафиксированными зависимостями:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Задайте переменные из .env.example. CRYPTOPANIC_API_URL должен содержать ваш рабочий URL API. Для Selenium требуется Chrome и совместимый драйвер. При запуске скрипт обращается к внешним сервисам и отправляет сообщения.

Переменные окружения: `CRYPTOPANIC_API_URL`, `DEEPL_AUTH_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Образец находится в [.env.example](.env.example). Сам файл .env автоматически не загружается: исходники читают окружение процесса. Значения нужно передать перед запуском, например в PowerShell:

```powershell
$env:CRYPTOPANIC_API_URL = "YOUR_VALUE"
```

После подготовки настроек и необходимых данных основная точка входа:

```powershell
python telegram_bot_cryptopanic_news.py
```

`requirements.txt` сохранён из проекта. Это снимок окружения, а не гарантия совместимости с новейшей версией Python. Для старых проектов могут потребоваться соответствующая версия Python и настройка системных компонентов.
