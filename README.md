# Telegram-бот для перевода криптоновостей

Рабочее название: `telegram_bot_cryptopanic_news`.

Скрипт связывает новостной источник, браузерный парсинг, машинный перевод и Telegram. Он получает список CryptoPanic, открывает выбранную публикацию, переводит заголовок и текст на русский и формирует сообщение со ссылкой на источник.

## Возможности

- Получает заголовки, ссылки и сведения об источниках через API CryptoPanic.
- Открывает выбранную страницу в Chrome и извлекает текст из её HTML-элементов.
- Переводит заголовок и основное содержимое через DeepL.
- Отправляет оформленное сообщение в Telegram с указанием источника и исходной ссылки.

## Как устроен проект

### Получение новости

[`telegram_bot_cryptopanic_news.py`](telegram_bot_cryptopanic_news.py)

Первый блок запрашивает CryptoPanic и выбирает заголовок, адрес и источник публикации.

### Извлечение и перевод

[`telegram_bot_cryptopanic_news.py`](telegram_bot_cryptopanic_news.py)

Selenium получает текст со страницы, после чего клиент DeepL переводит его и заголовок.

### Публикация

[`telegram_bot_cryptopanic_news.py`](telegram_bot_cryptopanic_news.py)

Финальный блок собирает Markdown-сообщение и отправляет его методом sendMessage.

## Технологии и их роль

- **Requests**: Запросы к CryptoPanic и Telegram Bot API.
- **Selenium**: Работа со страницей в Chrome и извлечение текста через DOM.
- **DeepL**: Перевод заголовка и содержимого публикации на русский язык.

## Подготовка и запуск

Создайте отдельное окружение и установите исходные зависимости:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Задайте переменные из .env.example. CRYPTOPANIC_API_URL должен содержать ваш рабочий URL API. Для Selenium требуется Chrome и совместимый драйвер. При запуске скрипт обращается к внешним сервисам и отправляет сообщения.

Переменные окружения: `CRYPTOPANIC_API_URL`, `DEEPL_AUTH_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Образец находится в [.env.example](.env.example). Сам файл .env автоматически не загружается: исходники читают окружение процесса. Значения нужно передать перед запуском, например в PowerShell:

```powershell
$env:CRYPTOPANIC_API_URL = "YOUR_VALUE"
```

После подготовки настроек и необходимых данных основная точка входа:

```powershell
python telegram_bot_cryptopanic_news.py
```

`requirements.txt` сохранён из проекта. Это снимок окружения, а не гарантия совместимости с новейшей версией Python. Для старых проектов могут потребоваться соответствующая версия Python и настройка системных компонентов.

## Контекст и ограничения

Проект 2023 года демонстрирует последовательную обработку данных между несколькими сервисами. В представленной версии за запуск обрабатывается одна выбранная запись из ответа API. Планировщик публикаций и учёт уже отправленных новостей в этом скрипте не предусмотрены.
